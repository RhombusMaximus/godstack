Six tools that earn their keep. No affiliate links, no sponsors — each one installed, exercised, and kept on a working machine. Star counts are live from GitHub.

01
Reverse Engineering
REA

Reverse-engineer anything with agents — shipped app behavior down to native code. 200+ MCP tools across binaries, Electron/JavaScript, Android, firmware, packet captures, and live runtime observation, with an evidence ledger that keeps every claim tied to what was actually observed.

423,023 ★ TypeScript 207 MCP tools github.com/morluto/rea
02
Agent Reach
Agent Reach

Give your agent eyes on the whole internet. One CLI, one JSON envelope: login-walled platforms, video transcripts, Chinese platforms, and clean structured data. Strictly read-only, never logs in for you.

108,098 ★ Python 14 channels github.com/Panniantong/agent-reach
03
Security
security-audit-skill

A coding-agent skill that runs six-phase security audits: reconnaissance, coverage-led hunting, adversarial validation — the verifier's job is to disprove the finder — and schema-validated findings. The single-repo seed of Cloudflare's vulnerability-discovery harness.

57,422 ★ JavaScript MIT github.com/cloudflare/security-audit-skill
04
Business Intelligence
Metabase

The easy, open-source way for everyone to ask questions of data — GUI query builder for the rest of us, a real SQL editor for power users, dashboards, alerts, full-app embedding. Now with a first-class Agent API so your AI can query the warehouse too.

50,117 ★ Clojure AGPL / open-core github.com/metabase/metabase
05
Documents
Paperless-ngx

Scan, OCR, index, archive. The document manager that eats the paper pile and hands back a searchable archive — with AI-suggested tags, semantic search, and chat over your own documents. Docker up in minutes.

47,603 ★ Python · Django GPL-3.0 github.com/paperless-ngx/paperless-ngx
Proof of work — forged with the stack

Gravity Melee

Star Control II's Super Melee, rebuilt as a vanilla-JS canvas game: all 25 ships, their stats, sprites, captains, weapon sounds, and the full 63-module soundtrack reverse-engineered out of the original Ur-Quan Masters binaries and sources with REA — the number-one tool on this list doing the job it's ranked for.

The single-player campaign is under construction: a 502-system 3D hyperspace map is live, and the planetary lander minigame just shipped.
